# Project plan

This is a working planning outline, not an approved product specification.

## Confirmed context

- Name: Re-market.
- Product: a future marketplace.
- Working repository: TanevAnton/re-market.

## Scope decisions

| Topic | Question to resolve |
| --- | --- |
| Audience | Who are the first buyers and sellers? |
| Inventory | Which categories and item conditions are supported? |
| Launch market | Which countries, languages, and currencies are needed? |
| Transaction model | Listings and enquiries, or integrated checkout? |
| Seller access | Individuals, businesses, or both? |
| Operations | Who handles delivery, returns, disputes, and moderation? |
| Revenue | What business model should the first release test? |
| Technology | Which stack and hosting fit the agreed scope and team? |

## Proposed milestones

1. **Discovery:** agree on the audience, marketplace model, and first-release scope.
2. **Design:** map buyer, seller, and administrator journeys; review a clickable prototype.
3. **Implementation:** build the agreed features and document local setup.
4. **Validation:** check core journeys, access controls, mobile usability, and operational readiness.
5. **Pilot:** release to a limited group, collect feedback, and prioritize improvements.

No delivery dates or implementation commitments have been set.

## Task template

For each agreed task, record:

- Goal and user need.
- Acceptance criteria.
- Owner.
- Dependencies.
- Validation method.

## Next step

Agree on the marketplace model and the smallest useful first release before choosing a stack.
