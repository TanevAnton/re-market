## Current state

The repository holds project documentation, original brand assets, and the standalone Python price tracker in `apps/price-tracker`. The tracker samples public PC component offers for Bulgaria and exports reviewable data; it does not change Shopify or configurator prices. Marketplace scope, technology stack, and launch timeline are still to be agreed.
